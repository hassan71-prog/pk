Build a complete production-ready Progressive Web App (PWA) called “TaskEarn PK”, designed as a legitimate rewards-and-tasks platform for users in Pakistan.

IMPORTANT:

- This must be a real functional web application, not a static UI mockup.
- Build the frontend, backend, database, authentication, admin panel, APIs, PWA installation support, and Telegram Mini App integration.
- Do NOT create a fake cryptocurrency, fake mining system, fake investment scheme, or guaranteed-profit system.
- Points/rewards must be backed by actual platform revenue such as sponsored tasks, affiliate commissions, or paid promotional campaigns.
- Never tell users that points are guaranteed to have monetary value unless an actual redemption system and sufficient funds exist.

3. POINTS SYSTEM

Implement a secure points ledger.

Every points change must create a transaction record.

Types:

- daily_reward
- task_reward
- referral_reward
- bonus
- admin_adjustment
- withdrawal
- reversal

Never trust the frontend to add points.

All balance changes must happen server-side.

Use database transactions to prevent double rewards and race conditions.

4. DAILY REWARD

Create a daily check-in system.

Rules:

- One daily reward per eligible user per calendar day.
- Server must determine whether the user already claimed it.
- Prevent duplicate claims through database constraints/transactions.
- Show countdown or next available date when appropriate.

Example:

Day 2 → +150
Day 3 → +200
